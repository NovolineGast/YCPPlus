混淆保护技术

从字节码到 Native 代码

核心混淆

@StringObfuscate 字符串加密 字符串常量加密存储，运行时动态解密
@NumberObfuscate 数字混淆 数值计算表达式复杂化
@FlowObfuscate 控制流混淆 插入虚假分支和跳转
@CallEncryption 调用加密 方法调用关系加密
@InvokeDynamic 动态调用 invokedynamic 指令转换
@Rename 重命名 类/方法/字段名随机化

高级保护

@Native Native 保护 Java 转换为 C++ + VMProtect
@VMProtectVirtualization 虚拟化保护 代码虚拟机执行
@VMProtectMutation 变异保护 代码变异
@VMProtectUltra 终极保护 最高级别保护
@DebuggerCheck 防调试 运行时调试器检测
@TamperPrevention 防篡改 代码完整性验证

快速开始

注解驱动的代码保护

Java 
import com.yumegod.yumecloudprotection.annotations.*;

public class MyApp {
    @StringObfuscate
    private static final String API_KEY = "secret_key_123";

    @NumberObfuscate
    private static final int MAX_USERS = 1000;

    @FlowObfuscate
    public void criticalMethod() {
        // 核心业务逻辑
    }

    @Native
    @VMProtectUltra
    public String validateLicense(String key) {
        // 授权验证逻辑
    }
}
Bash 
cd obfuscator
gradle shadowJar
java -jar build/libs/obfuscator-1.2.jar \
  --input YourApp.jar \
  --output YourApp-obfuscated.jar
