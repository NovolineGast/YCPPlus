快速开始

YCPPlus 提供两种核心功能：代码混淆保护和自托管授权服务器。以下是快速上手指南。

使用混淆器

在 Java 源码中通过注解标记需要保护的方法与字段，随后使用混淆器构建受保护的产物。

Javaimport com.yumegod.yumecloudprotection.annotations.*;

public class MyApp {
    @StringObfuscate
    private static final String API_KEY = "secret_key_123";

    @NumberObfuscate
    private static final int MAX_USERS = 1000;

    @FlowObfuscate
    public void criticalMethod() {
        // 核心业务逻辑
    }

    @Native
    @VMProtectUltra
    public String validateLicense(String key) {
        // 授权验证逻辑
    }
}

使用 Gradle 构建混淆器并处理目标 Jar：

Bashcd obfuscator
gradle shadowJar
java -jar build/libs/obfuscator-1.2.jar \
  --input YourApp.jar \
  --output YourApp-obfuscated.jar

或启动图形界面进行交互式配置：

Bashcd obfuscatorgui
gradle shadowJar
java -jar build/libs/obfuscatorgui-1.2.jar

部署授权服务器

使用 Docker Compose 一键启动授权服务，并完成管理员初始化：

Bashdocker-compose up -d ycp-auth-python
docker-compose up -d ycp-auth-go
curl -X POST http://localhost:13337/init_admin \
  -d "app=MyApp" \
  -d "password=YourSecurePassword"
快速启动脚本

Windows 用户：运行 start_server.bat

Linux/macOS 用户：运行 ./start_server.sh

配置客户端

修改混淆器源码中的授权服务器地址，指向你部署的服务器实例：

Java// obfuscator/src/main/java/com/yumegod/obfuscator/YumeCloudProtection.java
// 第 60 行
public static String authorizationURL = "http://你的服务器IP:13337/";

重新构建混淆器以使配置生效：

Bashcd obfuscator
gradle shadowJar

授权服务器 API

自托管授权服务器提供完整的密钥管理 API，兼容原始 Admin Panel 协议。

性能基准

Go 版本：约 15,000 req/s（P95: 10ms）

Python 版本：约 500 req/s（P95: 200ms）

端点
功能
参数
POST /init_admin
初始化管理员
app, password
POST /admin_login
管理员登录
app, password
POST /admin
管理命令
app, password, command
POST /login
客户端授权验证
app, key

管理命令

通过 /admin 端点传入 command 参数执行管理操作：

Key <数量> <天数> 生成密钥（1-50 个，1-9999 天）
Ban <密钥> 封禁密钥
Reset <密钥> 重置密钥
LastLogin <密钥> 查询上次登录时间

生成 10 个 30 天有效期的密钥，并封禁指定密钥：

Bashcurl -X POST http://localhost:13337/admin \
  -d "app=MyApp" \
  -d "password=YourPassword" \
  -d "command=Key 10 30"

curl -X POST http://localhost:13337/admin \
  -d "app=MyApp" \
  -d "password=YourPassword" \
  -d "command=Ban ABCD-1234-EFGH-5678"

部署指南

YCPPlus 授权服务器支持多种部署方式，推荐使用 Docker 进行生产环境部署。

Docker 部署

构建镜像并以守护态启动 Go 与 Python 实例：

Bashdocker-compose build
docker-compose up -d ycp-auth-go
docker-compose up -d ycp-auth-python
docker-compose logs -f ycp-auth-go

手动部署

Python 版本依赖 Flask，直接运行入口脚本：

Bashcd server_python
pip install -r requirements.txt
python app.py

Go 版本编译为单一二进制后运行：

Bashcd server_go
go build -o auth-server main.go
./auth-server

Nginx 反向代理

通过 Nginx 提供 HTTPS 终止与域名转发：

Nginxserver {
    listen 443 ssl;
    server_name auth.yourdomain.com;

    ssl_certificate     /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://127.0.0.1:13337;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
